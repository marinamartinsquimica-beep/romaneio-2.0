Conexão do sistema

Esta cópia está preparada para autenticar no Microsoft 365 e trocar registros por uma lista do SharePoint. A configuração é salva localmente neste aparelho.

A lista precisa ter as colunas Title (com valores exclusivos), RecordType, Scope e Payload. Para publicar planilhas, informe também o ID da biblioteca de documentos. O cadastro do aplicativo Microsoft deve permitir este endereço de retorno.
